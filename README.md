# Веб-приложение со счётчиком просмотров в Docker 🐳

Простое веб-приложение на **Node.js (Express)**, которое подключается к базе данных **PostgreSQL**, считывает количество посещений страницы и сохраняет их в постоянное хранилище (Volume).

## 🚀 Технологии в проекте
* **Backend:** Node.js (Express)
* **Database:** PostgreSQL 16
* **Orchestration:** Docker Compose
* **Network Drivers:** Изолированные сети `bridge` (`frontend-net`, `backend-net`)

---

## 🛠 Инструкция по запуску

### 1. Подготовка окружения
Перед запуском склонируйте репозиторий и создайте локальный файл конфигурации `.env` на основе примера:
```bash
cp .env.example .env
```
_При необходимости откройте файл `.env` и укажите свои порты или пароли для базы данных._

### 2. Запуск контейнеров
Разверните и соберите проект в фоновом режиме одной командой:
```bash
docker-compose up -d --build
```

### 3. Проверка работы
* Откройте браузер и перейдите по адресу: **`http://localhost:9090`** (или указанный вами порт).
* При каждом обновлении страницы (F5) счётчик просмотров будет увеличиваться. Это подтверждает успешное сетевое взаимодействие веб-приложения и БД.

### 4. Проверка внешних томов (Сохранение данных)
Чтобы убедиться, что настройки томов работают корректно:
1. Остановите и уничтожьте контейнеры: `docker-compose down`
2. Запустите их снова: `docker-compose up -d`
3. Снова откройте страницу в браузере. Счётчик **не сбросится**, а продолжит расти с последнего значения, так как данные сохранены в именованном томе `pgdata`.
